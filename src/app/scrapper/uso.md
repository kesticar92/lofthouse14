Aquí se encuentran 2 algoritmos de scrapper. El primero es para obtener los datos de google place ('google_scrapper.py') y el segundo es para obtener las reseñas de booking ('booking_scrapper.py').

los output's de ambos scrapper, son json y se encuentran en la carpeta reviews

Para ejecutarlos se necesita tener un entorno de python, este proyecto no tiene librerias externas a python, por lo que solo se necesita tener python instalado. O en su defecto ejecutarlos en Google Colab.
